# Virtualization-Lab

This objective of these labs is use KVM to demystify virtualization concepts such as virtual machine, virtual CPU and so on.

The labs are composed of several parts with different goals:
* **Lab1** -- Creating and deploying a simple virtual machine.
* **Lab2** -- Running a C application inside a virtual machine and handling the VM exits.

Each lab contains an intruction file (INSTRUCTIONS.md)
